Render Display Rewrite
==========================


## Install

1. Install the latest version of [SMAPI](https://smapi.io).
2. Download this mod and unzip it into `Stardew Valley/Mods`.
3. Run the game using SMAPI.

## Configuration
**This mod does not support GMCM, because there is no reasonable way to apply the config while the game is launched. You must edit the config.json file.**

1. **CacheTileRotations**: Whether or not to use more memory to cache the tile rotations. Doing so will be slightly faster, but will use a tad bit more memory.

## Compatibility

* Works with Stardew Valley 1.6.15+ on Linux/macOS/Windows.
* Works in single player, multiplayer, and split-screen mode.
* Should be compatible with most other mods.
